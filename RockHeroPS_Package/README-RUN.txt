COMANDO PARA RODAR DE QUALQUER PASTA

Opção 1 - CMD (recomendada):
  RUN.cmd  (ou RUN_FROM_ANY_FOLDER.cmd)

Opção 2 - PowerShell:
  RUN.ps1  (ou RUN_FROM_ANY_FOLDER.ps1)

Como usar:
1. Copie toda a pasta RockHeroPS_Package para outro computador
2. Abra CMD ou PowerShell EM QUALQUER PASTA
3. Navegue até a pasta (ou não) e execute um dos arquivos acima usando caminho completo OU abra a pasta e clique duas vezes

Exemplo abrindo CMD em C:\ e rodando:
  C:\Users\bruno\Desktop\RockHeroPS_Package\RUN.cmd

Exemplo PowerShell de qualquer pasta:
  & "C:\CAMINHO\RockHeroPS_Package\RUN.ps1"
